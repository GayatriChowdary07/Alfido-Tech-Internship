# Task 1 - Customer Behavior Analysis

## Objective
Analyze customer purchasing behavior using Python and Tableau to identify trends and generate business insights.

## Tools Used
- Python (Pandas)
- Jupyter Notebook
- Tableau

## Dataset
Ecommerce Customer Data

## Project Files
- customer_behavior_analysis.ipynb
- Customer Behavior Analysis Report.pdf
- Dashboard.png
- ecommerce_customer_data_custom_ratios.csv

## Key Insights
- Books and Clothing recorded the highest total purchase amounts.
- Customer purchases are spread across different age groups.
- Monthly purchase trends remain relatively stable throughout the year.
