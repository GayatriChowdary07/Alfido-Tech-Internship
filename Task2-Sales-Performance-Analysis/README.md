# Task 2 - Sales Performance Analysis

## Objective
Analyze Superstore sales data to identify sales trends, regional performance, and top-performing products. Generate business insights using Python and Tableau.

## Tools Used
- Python
- Pandas
- Matplotlib
- Tableau
- Jupyter Notebook

## Dataset
- Source: Kaggle
- Dataset: Superstore Sales Dataset

## Project Workflow
- Imported and explored the dataset
- Cleaned and prepared the data
- Performed summary statistics
- Calculated key performance indicators (KPIs)
- Created visualizations in Tableau
- Generated business insights and recommendations

## KPIs
- Total Sales
- Average Sales
- Maximum Sales
- Minimum Sales
- Total Orders

## Dashboard Visualizations
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by State
- Sales by Category & Sub-Category

## Files Included
- sales_analysis.ipynb
- Sales Performance Analysis Report.pdf
- Dashboard.png

## Outcome
This project provides insights into sales performance, product demand, and regional trends to support better business decisions.
