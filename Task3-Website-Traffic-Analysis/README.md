# Task 3 - Website Traffic Analysis

## Objective
Analyze website traffic data to understand user behavior, identify traffic sources, evaluate engagement metrics, and provide recommendations to improve website performance.

## Tools Used
- Python
- Pandas
- Matplotlib
- Tableau
- Jupyter Notebook

## Dataset
- Source: Kaggle
- Dataset: Website Traffic Analysis Dataset

## Project Workflow
- Imported and explored the dataset
- Cleaned and prepared the data
- Performed summary statistics
- Calculated website KPIs
- Built Tableau dashboard
- Generated business recommendations

## KPIs
- Total Page Views
- Average Session Duration
- Average Bounce Rate
- Average Time on Page
- Average Conversion Rate

## Dashboard Visualizations
- Traffic Source Distribution
- Page Views by Traffic Source
- Average Session Duration by Traffic Source
- Conversion Rate by Traffic Source

## Files Included
- website_traffic_analysis.ipynb
- Website Traffic Analysis Report.pdf
- Dashboard.png

## Outcome
This project identifies user engagement patterns, evaluates traffic performance, and provides actionable recommendations to improve website conversions and user experience.
