# Task 1 - Customer Behavior Analysis

## Objective
Analyze customer purchasing behavior to identify buying patterns, trends, and key business insights using Python and Tableau.

## Tools Used
- Python
- Pandas
- Matplotlib
- Tableau
- Jupyter Notebook

## Dataset
- Source: E-commerce Customer Dataset
- The dataset contains customer purchase records, product information, payment details, customer demographics, and return status.

## Project Workflow
- Imported and explored the dataset
- Performed data cleaning
- Checked for missing values and duplicate records
- Generated summary statistics
- Calculated key metrics
- Created Tableau dashboard
- Generated business insights and recommendations

## Key Metrics
- Total Customers
- Total Purchases
- Average Purchase Amount
- Maximum Purchase Value
- Minimum Purchase Value
- Mean, Median, and Mode
- Missing Values
- Data Types

## Dashboard Visualizations
- Customer Age Distribution
- Purchase Amount by Category
- Payment Method Distribution
- Returns Analysis

## Files Included
- customer_behavior_analysis.ipynb
- Customer Behavior Analysis Report.pdf
- Dashboard.png

## Outcome
This project analyzes customer purchasing behavior to uncover spending patterns, customer preferences, and product performance. The insights can help businesses improve marketing strategies, customer retention, and overall sales performance.
